# Discord Self MCP: доработанный форк

Форк [Microck/discord.py-self-mcp](https://github.com/Microck/discord.py-self-mcp)
на базе версии 1.8.1. Лицензия исходного проекта сохранена.

## Возможности форка

- Поиск по индексу Discord с фильтрами по серверу, каналу, автору и датам.
- Пакетный поиск с общим бюджетом вывода, удалением повторов и продолжением.
- Контекст сообщения и чтение сообщений, на которые отвечали.
- Поиск названий активных и архивных тем форума.
- Сохранённые аккаунты, список профилей и переключение без перезапуска MCP.
- Общие серверы и друзья относительно активного аккаунта.
- Проверка текущего членства через API вместо выводов по кэшу.
- Обязательное время «печатает…» перед отправкой.
- Компактный вывод: авторы, роли и каналы один раз на ответ; подробности по запросу.

Сохранение аккаунтов использует Windows DPAPI. Форк проверен на Windows;
в хранилище находятся зашифрованные токены текущего пользователя Windows.

## Установка

Нужен Python 3.10 или новее. В PowerShell:

~~~powershell
git clone --branch codex/discord-mcp-enhancements https://github.com/Yozh2709/discord.py-self-mcp.git
cd discord.py-self-mcp
python -m venv .venv
.venv\Scripts\python.exe -m pip install .
~~~

В MCP-клиенте укажите абсолютный путь к установленному Python, аргументы
и переменную окружения DISCORD_TOKEN. Пример для формата mcpServers:

~~~json
{
  "mcpServers": {
    "discord-self": {
      "command": "C:\\path\\discord.py-self-mcp\\.venv\\Scripts\\python.exe",
      "args": ["-m", "discord_py_self_mcp.main"],
      "env": {"DISCORD_TOKEN": "YOUR_USER_TOKEN"}
    }
  }
}
~~~

Путь и токен в примере — заглушки. Команды npm из исходной документации
устанавливают upstream; для доработок этого форка используйте исходники выше.

## Аккаунты

Первый успешно подключённый токен сохраняется как main.

- list_accounts возвращает имена профилей и активный аккаунт.
- save_account принимает account и token, проверяет токен и сохраняет профиль.
  Для замены существующего имени требуется replace=true.
- switch_account принимает account и переключает текущий MCP на сохранённый профиль.

Новое подключение проверяется перед заменой текущего. Текущие команды завершаются
до переключения. Выбранный профиль используется при следующем запуске.
Все чаты, подключённые к одному процессу MCP, используют его активный аккаунт.

DISCORD_ACCOUNTS_FILE задаёт путь к хранилищу. По умолчанию это
LocalAppData/discord-self-mcp/accounts.json. DISCORD_ACCOUNT позволяет явно выбрать
стартовый профиль. Подробности ошибок подключения видны через list_accounts.

## Чтение и поиск

search_messages_advanced принимает ровно одно из channel_id или guild_id.
Дополнительно доступны query, author_id, after, before, oldest_first и offset.
Для нескольких слов используйте search_messages_batch с queries.
Для продолжения берите next_offset из ответа с теми же фильтрами.

get_message_context принимает channel_id и message_id. По умолчанию читает
10 сообщений до и после, а также до двух родительских сообщений ответа.
reply_depth=0 отключает дополнительное чтение родителей.

search_forum_topics принимает forum_id и query; поиск идёт по названиям тем.
get_guild_member проверяет текущее членство через API.
get_user_mutuals принимает user_id и возвращает общие серверы и друзей.
Недоступные данные не считаются нулём мутуалов.

Обычный вывод содержит справочник авторов с названием высшей роли из кэша.
Цветов и повторяющихся служебных полей нет. details=true включает подробный формат.
Получение роли для сообщения не делает дополнительных запросов участников.

## Отправка

send_message и send_thread_message требуют typing_seconds: число больше 0
и не больше 60, допускаются дроби. Сначала показывается индикатор набора,
затем отправляется сообщение. Значения по умолчанию нет.

## Проверка

Тесты используют имитацию Discord и не отправляют настоящих сообщений:

~~~powershell
.venv\Scripts\python.exe -m pip install -e ".[test]"
.venv\Scripts\python.exe -m pytest -q
~~~

Переподключите MCP после обновления кода, чтобы клиент загрузил новые схемы.
